SimpleDoc HWP v9
================

V9 핵심: 선택영역 엔진 재설계
-----------------------------
V9은 여러 줄/여러 문단 선택에서 삭제·줄간격·정렬·글자 서식·모양 복사/붙이기가
서로 다른 방식으로 Selection을 해석하던 문제를 없애기 위해 선택 처리 계층을 다시 작성했습니다.

1. 선택영역 Bookmark
-------------------
- 문서 선택 시작/끝점을 documentRoot 기준 DOM path + offset으로 별도 저장합니다.
- 툴바/드롭다운을 클릭해 브라우저의 실제 Selection 표시가 풀려도 원래 선택을 복원합니다.
- page-inner offset 0으로 잡히는 페이지 첫 줄도 정상 선택으로 처리합니다.
- 다른 모듈이 커서를 이동할 때 savedRange와 bookmark를 함께 갱신합니다.

2. 여러 줄 / 여러 문단 서식
---------------------------
- 줄 간격, 정렬, 문단 스타일: 선택에 걸린 모든 실제 문단을 탐색해 각각 적용합니다.
- 글꼴, 크기, 굵게, 기울임, 밑줄, 색, 자간 등 문자 서식:
  여러 p/h/li를 하나의 span으로 감싸지 않고 선택된 각 텍스트 조각만 개별 span으로 처리합니다.
- 페이지 첫 문단에서 선택을 시작해도 첫 문단이 누락되지 않습니다.
- 여러 A4 페이지에 걸친 선택도 문단 스타일 적용이 가능합니다.

3. 모양 복사 / 붙이기
--------------------
- Alt+C 기준을 유지합니다.
- 선택 시작점이 page-inner 경계여도 실제 첫 선택 글자를 찾아 글자 모양 기준으로 사용합니다.
- 문단 모양은 실제 첫 선택 문단에서 가져옵니다.
- 여러 문단을 대상 블록으로 잡으면 모든 문단에 글자 + 문단 모양을 적용합니다.
- Esc로 모양 붙이기 대기 상태를 취소할 수 있습니다.

4. 다중문단 삭제
----------------
- Delete/Backspace의 비어 있지 않은 선택영역은 브라우저 기본 동작에 맡기지 않고
  V9 Selection 엔진이 직접 처리합니다.
- 여러 문단을 가로질러 삭제하면 시작/끝에 남는 텍스트를 Word 계열 편집처럼 한 문단으로 합칩니다.
- 선택 범위에 개체가 완전히 들어가면 해당 개체도 본문 흐름의 한 단위처럼 함께 삭제됩니다.
- 개체 내부 편집영역과 외부 본문을 동시에 걸친 위험한 선택은 구조 보호를 위해 차단합니다.
- 박스/표 내부 내용만 모두 삭제해도 개체 껍데기와 셀 구조는 유지합니다.

5. Ctrl+A
---------
- 각 A4가 별도 contenteditable 영역이어도 Ctrl+A는 현재 페이지만이 아니라 문서 전체를 선택합니다.

6. 삽입 기능 통합
----------------
- 선택한 텍스트를 기호/텍스트/블록 개체/쪽 나누기로 교체할 때도 동일한 V9 삭제 엔진을 사용합니다.
- 이전처럼 삽입 기능별 range.deleteContents 결과가 달라지는 문제를 줄였습니다.

7. 기존 V8 기능 유지
--------------------
- 원자적 개체 Delete / Backspace
- 표 전체 너비 및 우하단 resize handle
- 자동 페이지 정밀 reflow
- 긴 문단 tail 분할
- 큰 표 행 단위 페이지 분할
- PDF / DOCX / YKDOC 저장
- 한/글 계열 단축키

참고한 워드프로세서 기준
----------------------
- Microsoft Word: 여러 단락 선택/서식, Format Painter, 선택 텍스트 삭제, 표 내용과 표 자체 삭제 구분
- 한컴 한/글: Alt+C 모양 복사/붙이기, 블록 지정 글자/문단 모양 일괄 적용, Ctrl+A 전체 선택

실행
----
index.html을 브라우저에서 실행합니다.
