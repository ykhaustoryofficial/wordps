편집할 HTML 파일을 열어주세요
앞서 만든 입찰공고·세부현황서·별지서식·평가표 HTML을 그대로 불러와 편집할 수 있습니다.
TIP 파일을 이 영역에 끌어다 놓아도 됩니다.
권장 사용법
1. 구조 보호 상태에서 문구와 표 내용만 수정합니다.
2. 표 셀은 클릭으로 1개 선택, Ctrl/Cmd+클릭으로 추가선택, Shift+클릭으로 범위선택할 수 있습니다.
3. 셀 선택 모드를 켜면 표 위를 드래그해 여러 셀을 한 번에 선택할 수 있습니다.
4. 선택한 셀에 정렬·글자크기·서식 붙여넣기를 일괄 적용할 수 있습니다.
5. 행 +/−, 열 +/−로 표 구조를 수정합니다.
6. 셀 선택 후 너비·높이(px)를 입력해 정확히 지정하거나, 셀의 오른쪽/아래쪽 경계를 드래그해 직접 크기를 조정할 수 있습니다.
7. 자동을 누르면 선택 셀의 직접 지정한 크기를 해제합니다.
8. 서식 복사/붙여넣기는 Alt+C / Alt+V 단축키도 지원합니다.
9. 레이아웃 자체를 고칠 때만 자유 편집, HTML 코드를 직접 고칠 때는 HTML을 사용합니다.
10. 완료 후 저장 또는 다른 이름으로 저장을 누릅니다.
11. 편집 화면의 흰 종이는 실제 A4 출력 비율입니다. 긴 페이지는 자동으로 축소되며, 축소되는 만큼 편집 폭을 넓혀 불필요한 줄바꿈을 줄입니다.
12. 출력 설정에서 상·하·좌·우 여백과 긴 페이지의 가로폭 자동 확장 여부를 조절할 수 있습니다.
13. PDF 저장은 별도 캔버스 렌더링을 하지 않고, 현재 편집 화면과 동일한 페이지 배치를 A4 인쇄 구조로 구성합니다. 인쇄창에서 PDF로 저장을 선택하세요.

Chromium 계열 브라우저에서는 원본 HTML 파일에 직접 저장할 수 있고, Safari 등에서는 새 HTML 파일로 내려받습니다.
