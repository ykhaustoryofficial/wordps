V8에서 중점 확인한 기준
----------------------
- 일반 문단 끝에서 바로 뒤 개체 Delete → 개체 즉시 삭제
- 개체 뒤 문단 첫 위치 Backspace → 개체 즉시 삭제
- 개체 내부 편집영역은 바깥 본문과 삭제 경계를 공유하지 않음
- 드래그 범위에 완전히 포함된 개체는 본문 문자처럼 함께 삭제
- 표 전체 너비 조절값 및 resize handle 정상
- 페이지 경계를 넘는 첫 블록을 찾아 overflow 부분만 이동
- 긴 일반 문단은 tail 분할, 앞 문단은 유지
- 나눌 수 없는 박스 개체는 해당 개체만 통째로 다음 페이지 이동
- 큰 표는 행 단위 분할
- 표 사용자 지정 너비는 분할 뒤에도 유지
- 저장 데이터에서 편집용 object/resize handle 제거
